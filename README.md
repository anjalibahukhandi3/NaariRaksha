# NaariRaksha 🚨

A women safety Android application with SOS alerts, live location sharing,
shake detection, power button trigger, and fake call escape feature.

Current-Features:
- SOS emergency alert
- Send live location via SMS
- Shake to trigger SOS
- Power button SOS trigger
- Fake call escape screen

Current-Tech Stack
- Kotlin
- Android SDK
- Google Location Services
